📖 Grade 10 CAT — Quick notes

1. Hardware

Hardware is the physical parts of a computer that you can touch. Examples: keyboard, monitor, CPU, mouse and printer.

2. CPU

The Central Processing Unit executes instructions and processes data. The control unit directs operations; the ALU performs arithmetic and logical operations.

3. RAM

Random Access Memory temporarily stores programs and data currently in use. It is volatile, meaning its contents are lost when power is switched off.

4. Storage

SSD and HDD store files and applications long-term. Storage keeps data when the computer is switched off.

5. Operating system

An operating system manages hardware and software resources and provides an interface for users. Examples include Windows, macOS, Linux and Android.

6. Networks

A LAN covers a small area such as a school. A WAN connects networks over larger geographical areas. A router forwards data between networks.

7. Internet safety

Use strong unique passwords, enable two-factor authentication, check links before opening them and never share private information with strangers.
